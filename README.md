# דשבורד עסקי

אפליקציית ניהול לידים, אירועים ומשימות לעסק.

## תכונות

- **דשבורד** — KPIs, גרפים, השוואה שנתית וחודשית
- **לידים** — הזנה/עריכה/מחיקה, סינון, חיפוש
- **אירועים** — כל ליד שמסומן "נסגר" עובר אוטומטית לדף האירועים
- **ניתוח המרות** — מקורות, סוגי אירועים, סיבות אי-סגירה, פאנל המרה ותובנות
- **משימות** — תזכורות אוטומטיות

## תזכורות אוטומטיות

- **ליד "פולואפ"** — משימה בתאריך שנבחר בטופס
- **ליד "נסגר" (אירוע)**:
  1. שבוע לפני האירוע — שאלון לחתן (רק ברווקות)
  2. יומיים לפני האירוע — שאלון הכנה לאירוע, וידוא מילוי
  3. יום אחרי האירוע — שליחת קבלה
  4. יומיים אחרי החתונה — הודעה לכלה (רווקות / מקווה / הפרשת חלה, לפי שדה "תאריך החתונה")

## התראות לטלפון

כל בוקר ב-08:00 (שעון ישראל) נשלחת התראה נפרדת לכל משימה של היום, ועוד התראה אחת מרוכזת על משימות באיחור.

- **בדשבורד** — כפתור "הפעלת התראות" בתחתית התפריט, פעם אחת בכל מכשיר
- **שליחה** — `.github/workflows/notify.yml` מריץ את `scripts/notify/send.js`
- **Secrets נדרשים ב-GitHub** — `FIREBASE_SERVICE_ACCOUNT` (קובץ ה-JSON של חשבון השירות) ו-`VAPID_PRIVATE_KEY`
- **בדיקה** — ב-GitHub → Actions → "Daily task notifications" → Run workflow → `test`

## טכנולוגיה

- React 18 + Babel Standalone
- Chart.js
- Firebase Auth (Google Sign-In) + Firestore (סנכרון בין מכשירים)
